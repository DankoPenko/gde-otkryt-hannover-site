    Методика MVP

    Потенциал, а не прогноз прибыли

    Карточки заведений показывают модельную оценку жителей в закреплённых жилых домах OSM: площадь контура × этажность × 80% ÷ 45 м². Каждый дом закреплён за одним ближайшим заведением по прямой, отдельно внутри каждой категории. Это не перепись и не прогноз клиентов; неизвестные типы зданий исключены из оценки жителей.

    Рейтинг кандидатных зон доступен только для пекарен. Это отдельная демонстрационная модель: число жителей в этих зонах пока задано вручную. Оно не связано с распределением домов по заведениям.

    1. Доступность: расстояние по прямой переводится в приблизительные минуты, без маршрутов и барьеров. Радиусы сейчас скрыты.
    2. Конкуренция: снижаем балл, если рядом много похожих точек.
    3. Спрос: повышаем балл для плотных жилых кластеров.

    OSM не гарантирует полноту. Для реального решения нужно сверить выдачу с Google Maps и местными каталогами, а затем добавить Zensus 2022, аренду и пешеходный трафик.

    Для помещений считаем жилые дома, модельное население и конкурентов в пределах 800 м по прямой. Это окружение адреса, не эксклюзивный охват и не пешеходный маршрут. Для скрытых адресов расчёт отсутствует; ориентиры кварталов отмечены как приблизительные. Объявления — ручная подборка с датой проверки, без подтверждения свободности владельцем.
